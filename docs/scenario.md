## 1.3 게임 시스템

### 호감도 (Affinity)

- 범위: **-100 ~ +100** (초기값: 0)
- 캐릭터 5명 각각 독립적으로 관리
- 변동 원인: 선택지, 씬 이벤트, AI 프리톡 응답 (`[STATS: affinity +10]`)
- **최고 호감도 기록**: 갤러리용으로 최대치를 별도 저장 (감소해도 갤러리 해금은 유지)

### 플래그 시스템

- 불리언 플래그로 분기 관리 (`met_yuna`, `isDating_Seoyeon`, `day3_has_multiple_dates` 등)
- 선택지에 `condition` / `excludeCondition`으로 조건부 표시
- 복합 플래그: `has_any_contact` = `has_number_seyoun` OR `has_number_yuna` OR ...

### 분기 우선순위

1. **호감도 분기** (`affinityBranches`): 특정 캐릭터의 호감도에 따라 루트 결정
2. **플래그 분기** (`branches` + `condition`): 플래그 존재 여부로 분기
3. **최고 호감도 선택** (`selectByHighestAffinity`): 만난 캐릭터 중 호감도 1위로 자동 루팅

### AI 프리톡

- **인게임**: 시나리오 중 `type: 'free_talk'` 노드에서 발동. 기본 3턴 제한
- **갤러리**: TRUE LOVE 엔딩 클리어 후 해금. 턴 무제한
- 캐릭터 표정 변경 (`[EXPRESSION: shy]`), 호감도 변동 (`[STATS: affinity +10]`) 지원

### 갤러리 해금 조건

| 항목 | 조건 |
|------|------|
| 짧은 설명 | 호감도 < 80 |
| 풀 설명 | 호감도 >= 80 |
| 체중 스탯 | 호감도 >= 80 |
| 가슴 스탯 | 호감도 >= 100 |
| 표정 | 호감도 0~100 구간에서 비례 해금 |
| 비키니 | 호감도 100 AND 프리톡 100회 이상 |
| 갤러리 프리톡 | TRUE LOVE 엔딩 클리어 |

# 2. 플롯 차트

## Day 1 — 목요일: 첫 만남

### 아침 (morning)
```
전학 첫날 등교
  → 서연(학생회장)이 마중 → 학교 투어
  → [선택] 서연에 대한 첫 반응 (호감+10 ~ -30)
  → 복도 투어 중 대화 + AI 프리톡
  → 교실 도착 → 담임선생님 소개
  → [선택] 자기소개 스타일 (5가지) → 성격 플래그 설정
```

### 점심 (lunch)
```
[선택] 점심 장소 (6곳)
  → 서연과 함께: 옥상 도시락 씬 → 연락처 교환 가능
  → 유나(도서관): 첫 만남, 신비로운 분위기
  → 다인(체육관): 첫 만남, 배구 에너지
  → 보건실: 양호교사 첫 만남
  → 혼자 / 매점 / 교실 수면
```

### 방과후 (afterschool)
```
[선택] 방과후 행선지 (최대 9개, 조건부)
  → 서연: 학생회실 → 도와주기 → 카페 데이트 → 연락처
  → 유나: 도서관 → 미스터리 분위기
  → 다인: 체육관 → 떡볶이 데이트 가능
  → 보건실 / 교무실 / 귀가
  각 루트에서 연락처 교환 가능
```

### 밤 (night)
```
귀가 → 하루 회상 (만난 캐릭터별 조건부)
  → [선택] 일기 쓰기
  → [메시지 허브] 연락처 있는 캐릭터에게 메시지 전송 (복수 가능)
  → 취침 → Day 2로 전환
```

## Day 3 — 토요일 전날: 약속 충돌

> **핵심 테마**: "양다리를 걸 것인가, 한 명에게 충실할 것인가"

### 아침 (morning)
```
기상 (보건실 루트: 보건선생님 집에서 기상 → 서연이 다른 방향에서 오는 것 눈치챔)
  → 캐릭터별 아침 메시지 수신
  → [선택] 누구와 등교할지
  → 등교 중 AI 프리톡
  → 각 캐릭터가 주말 데이트 제안:
     서연: 토요일 2시 공원 분수대
     유나: 토요일 밤 8시 학교 뒷문
     다인: 토요일 아침 9시 체육관
     보건/담임: 주말 데이트 제안
  → [선택] 수락/거절 (수락 시 +8, 거절 시 -3~-15)
  → ★ 2명 이상 수락 시 → day3_has_multiple_dates 플래그 설정
     "잠깐... 나 방금 여러 명이랑 약속한 거 아니야?"
```

### 점심 (lunch)
```
양다리 감지 시:
  → 서연이 먼저 다가옴 → 다른 캐릭터와 충돌
  → [선택] 누구와 먹을지 / 다 같이 / 도망
     "다 같이" → ★ 재앙: 주말 약속이 전부 들통
       서연: "나만 특별한 게 아니었구나."
       유나: "알고 있었어." → "거짓말이야. 나도 몰랐어."
       → [선택] 사과 / 변명 / 도망 (-8 ~ -20)

단독 약속 시:
  → 해당 캐릭터와 평화로운 점심
```

### 방과후 (afterschool)
```
양다리 발각 시:
  → 서연이 복도에서 대질
    "정말 전부랑 약속한 거야?"
    → [선택] 솔직 / 변명 / 거짓말
  → 질투 캐릭터가 찾아와 경고

귀가길:
  → [선택] 누구와 함께 → 다른 캐릭터에게 목격될 수 있음
  서연: 핑키 프로미스 / 손잡기 (+8~+10)
  유나: 고양이 만남, 경고 메시지
  다인: 편의점 아이스크림, 진지한 대화
```

### 밤 (night)
```
귀가 → 메시지 확인
  양다리 시: 각 캐릭터가 추궁 메시지
    서연: "나만 만나는 거 맞지?"
    유나: "배신하면... 후회할 거야."
    → [선택] 거짓말 / 솔직 (거짓말 시 lied_to_X 플래그)

  → 취침
    양다리: ★ 악몽 — 어둠 속에서 모든 약속 상대의 목소리
      → [선택] 누구의 손을 잡을지 → 아무도 잡을 수 없음
    충실: +10 loyalty_bonus, 평화로운 잠
  → Day 4로 전환
```

### 아침 (morning)
```

  양다리 시: 죄책감 내면 독백
  → [선택] 아침 식사 / [선택] 복장 (캐주얼 vs 멋부림 → 멋부림 시 전원 +1)
```
