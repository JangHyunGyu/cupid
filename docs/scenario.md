# 1. 기획서

## 1.1 세계관

- **장르**: 학원 연애 시뮬레이션 (비주얼 노벨)
- **배경**: 한국의 일반 고등학교
- **시간 범위**: 목요일~일요일 (4일간, 게임 내 Day 1~5)
- **시점**: 1인칭 (전학생)
- **주인공**: 새 학교에 전학 온 학생. 이름은 플레이어가 직접 입력
- **분위기**: 밝은 학원 로맨스 아래, 각자의 상처와 비밀을 안고 살아가는 캐릭터들. 가벼운 일상과 무거운 속마음의 대비
- **톤**: 10대 후반~20대의 실제 한국어 구어체. 감정은 말보다 침묵과 행동으로. 느낌표보다 말줄임표
- **다국어**: 한국어, 영어, 스페인어, 일본어, 프랑스어, 독일어 (6개 언어)

## 1.3 게임 시스템

### 호감도 (Affinity)

- 범위: **-100 ~ +100** (초기값: 0)
- 캐릭터 5명 각각 독립적으로 관리
- 변동 원인: 선택지, 씬 이벤트, AI 프리톡 응답 (`[STATS: affinity +10]`)
- **최고 호감도 기록**: 갤러리용으로 최대치를 별도 저장 (감소해도 갤러리 해금은 유지)

### 플래그 시스템

- 불리언 플래그로 분기 관리 (`met_yuna`, `isDating_Seoyeon`, `day3_has_multiple_dates` 등)
- 선택지에 `condition` / `excludeCondition`으로 조건부 표시
- 복합 플래그: `has_any_contact` = `has_number_seyoun` OR `has_number_yuna` OR ...

### 분기 우선순위

1. **호감도 분기** (`affinityBranches`): 특정 캐릭터의 호감도에 따라 루트 결정
2. **플래그 분기** (`branches` + `condition`): 플래그 존재 여부로 분기
3. **최고 호감도 선택** (`selectByHighestAffinity`): 만난 캐릭터 중 호감도 1위로 자동 루팅

### AI 프리톡

- **인게임**: 시나리오 중 `type: 'free_talk'` 노드에서 발동. 기본 3턴 제한
- **갤러리**: TRUE LOVE 엔딩 클리어 후 해금. 턴 무제한
- 캐릭터 표정 변경 (`[EXPRESSION: shy]`), 호감도 변동 (`[STATS: affinity +10]`) 지원

### 갤러리 해금 조건

| 항목 | 조건 |
|------|------|
| 짧은 설명 | 호감도 < 80 |
| 풀 설명 | 호감도 >= 80 |
| 체중 스탯 | 호감도 >= 80 |
| 가슴 스탯 | 호감도 >= 100 |
| 표정 | 호감도 0~100 구간에서 비례 해금 |
| 비키니 | 호감도 100 AND 프리톡 100회 이상 |
| 갤러리 프리톡 | TRUE LOVE 엔딩 클리어 |

### 성격 & 말투

- 편지의 진실: 선배도 아팠고, 유나도 아팠고, 아무도 나쁜 사람이 아니었음
