# 시나리오 문체·연속성 재검수 — 2026-09-05

대상은 1~5일차 20개 파일의 3,040개 장면과 7개 언어의 140개 문구 파일이다. 한국어는 장면 전후와 선택에 따른 사건을 읽고 검토했다. 다국어는 전체 데이터의 누락·치환자·인코딩을 검사하고, 수정 구간의 뜻과 말투를 대조했다. 일본어의 시점과 영어의 메시지 표현 등은 별도 검색으로 추가 교정했다.

`im-not-ai` v2.0.0의 Codex 포트인 `humanize-korean`을 strict 모드로 적용했다. 문장 탐지, 윤문, 내용 보존 검토, 자연스러움 검토를 분리했다. 원본 지표는 낮은 위험으로 나왔지만 대화 장르의 비교 기준이 없어 에세이 기준으로 계산된 값이므로 수정 근거로 삼지 않았다. 실제로 어색하거나 모순되는 장면을 기준으로 판단했다.

## 반영 범위

182개 장면의 183개 항목과 AI 사건 기억 7개를 수정했다. 한국어 원본 검수 입력 대비 필드 단위 문자 변경률은 약 2.57%다. 장면 ID가 포함된 검수 입력을 분모로 사용한 수치이며, 문체 전체를 새로 쓴 비율을 뜻하지 않는다.

| 문제 | 반영한 행동과 대사 |
| --- | --- |
| 사과를 아직 보내지 않았는데 다음 날 모두 읽었다고 서술 | 입력창에 사과가 남은 상태에서 새 메시지를 받는다. |
| 유나가 연주한 곡을 주인공이 들려준 것처럼 회상 | 유나가 자기 연주에 대한 감상을 묻고 다음에는 상대의 취향도 알려 달라고 한다. |
| 유나의 고백 반응이 구두 대화를 읽은 편지처럼 취급 | “들었어. 근데 아직 대답은 못 하겠어.”로 답한다. |
| 다인의 부상 뒤 달렸다는 회상과 추가 배구 요청 | 걷는 동안에도 아팠다고 말하고 벤치에서 쉰다. 재활과 방송 활동은 병행한다. |
| 점심 종료 종이 울렸는데 대화가 계속됨 | 종료 종은 실제 점심 종료에만 남긴다. |
| 이미 떠나거나 앉은 인물을 다시 부르고 앉힘 | 중복 동작을 생략하고 실제로 이어지는 대화의 위치를 유지한다. |
| 단체채팅에 컵이 등장하거나 세 인물이 갑자기 나타남 | 메시지는 휴대폰 안에서 이어지고, 대면 만남에는 초대와 도착을 먼저 쓴다. |
| 책·원고·안내지를 건넨 뒤 소유자가 뒤바뀜 | 받은 사람의 손에 남기고 이후 지문과 대화를 맞춘다. |
| 공개 합평을 마친 다음에도 아직 공개하지 않았다고 설명 | 완료한 합평과 참석자를 다음날 대사·AI 기억에 반영한다. |
| 귀가 확인 갈등 때문에 교사가 진료나 상담을 거부 | 건강 지원은 유지하고 끝내지 못한 대화는 다음 상담으로 넘긴다. |
| 일요일을 졸업이나 이별처럼 “마지막 날”로 표현 | 전학 첫 주와 학교 행사 일정에 맞춰 말한다. |
| 고백 선택인데 실제 대사에는 마음을 밝히지 않음 | 세 학생 경로 모두 “좋아해”를 직접 말한다. |

서연의 자신감은 남기면서 허가·순종·쓸모로 상대를 평가하는 표현을 줄였다. 유나의 짧은 말과 책에 관한 표현은 유지하되, 맥락이 없는 문장·결말 비유는 필요한 감정으로 풀었다. 다인은 내기와 농담을 유지하면서 운동선수가 이해하지 못할 PR 농담과 의미 없는 포옹 카운트를 정리했다. 교사의 건조한 농담과 보건교사의 실용적인 말투는 과도한 규정 설명·진료 농담과 구별했다.

번역에서는 인물명, 화자, 고백 여부, 부상, 시점과 존칭을 먼저 맞췄다. 한국어의 말순서를 그대로 복제하지 않고 각 언어의 대화체로 옮겼다. 일본어 서술자의 `私`·`僕` 혼용 일부를 기존 `俺`와 맞췄고, 영어에서 메신저의 대화 미리보기를 기계적으로 `sentence`라고 부르던 곳을 다듬었다. 외부 원어민 감수는 실시하지 않았다.

## 문서와 실행 데이터

분기는 `assets/js/scenario/`, 표시 문구와 장면별 AI 맥락은 `assets/js/i18n/{언어}/`, 지속되는 사건 기억은 `assets/js/prompts.js`에 있다. `SCENARIO.md`는 이 실행 데이터에서 생성했다. 생성 문서의 안내도 실제 수정·검증 절차와 맞췄다. `docs/WRITING_GUIDE.md`에는 과도한 디테일 강요를 줄이고 사건·소품·호칭을 확인하는 기준을 반영했다.

중복 지문을 제거한 장면 ID는 분기용으로 보존한다. 기존 저장에서 그 장면으로 이어가도 다음 장면으로 넘어가며 보상이나 플래그를 다시 적용하지 않는다. 선택지의 결과, 보상·벌점, 본편 자유대화 횟수, 100점 PERFECT 기준과 다섯 경로의 120점 합산 예산은 변경하지 않았다. 졸업 및 성인 재회의 시간 간격도 유지했다.
