## Font delivery

- The original Pretendard variable font and its license remain unchanged.
- `scripts/build-home-font.py` derives a 1,361-codepoint home font from all eight
  home HTML files plus Latin, combining marks and punctuation.
- Initial Pretendard download: 2,057,688 bytes → 182,232 bytes, about 91.1% less.
  Chinese retains its existing system font stack and does not download Pretendard
  in the measured home view.
- The derivative uses the internal name Cupid Home Sans in accordance with the
  original reserved font name. Existing CSS family aliases, all weight axes,
  hints and layout features are preserved.
- `pretendard-home.css` assigns explicit Unicode coverage to the subset and its
  complete-font fallback. Unsupported emoji do not accidentally trigger a full
  font download.
- Game entry restores the original `pretendard.css` before loading story content.
  Direct game and gallery pages keep their original stylesheet. This avoids
  changing contextual punctuation shaping when rare and common glyphs mix.
- The initial approach applied the split font everywhere. A mixed-script visual
  check caught a contextual em-dash difference, so that approach was rejected.
  The final implementation limits the optimization to the home screen.
- Reproduction: install `fonttools[woff]==4.66.1`, then run
  `python scripts/build-home-font.py`. `config/home-font.json` records the original
  checksum, subset filename, codepoints and byte counts. No font build dependency
  is needed by the deployed application.
