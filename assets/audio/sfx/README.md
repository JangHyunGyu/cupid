# 효과음 파일 안내

## Runtime soundscapes (2026-10-15)

`synth:page_turn`, `synth:door`, `synth:notification`, `synth:volleyball` and
`synth:heartbeat` are generated by `SoundManager` at the browser's native
AudioContext sample rate. They need no downloaded sample files. The runtime
registry in `assets/js/sound.js` is also checked by the scenario validator.

Library, gym and rain ambience use an independent looping source. Existing SFX
volume and mute controls apply to both ambience and one-shot effects. The MP3
files below remain the existing affinity effects.

이 폴더에는 게임에서 사용되는 효과음(SFX) 파일들이 저장됩니다.

## 필요한 효과음 파일

다음 효과음 파일들을 이 폴더에 추가해주세요:

1. **affinity_up.mp3** (호감도 증가 효과음)
   - 밝고 경쾌한 종소리, 반짝임 소리, 하프 글리산도 등
   - 추천: 짧은 징글벨, 마법 반짝임, 성공 알림음
   - 길이: 0.5~1.5초

2. **affinity_down.mp3** (호감도 감소 효과음)
   - 낮은 피아노 음, 유리 깨지는 소리, 안타까운 음색
   - 추천: 실망 효과음, 무거운 탬버린, 실패 알림음
   - 길이: 0.5~1.5초

## 검색 키워드

### 호감도 증가용
- "magic sparkle", "success", "positive", "chime", "twinkle", "level up", "coin collect"

### 호감도 감소용  
- "negative", "fail", "error", "wrong", "sad tone", "glass break", "disappointment"

## 파일 형식
- MP3 또는 OGG 형식 권장
- 파일 크기: 50KB 이하 권장
- 비트레이트: 128kbps 이하 권장
