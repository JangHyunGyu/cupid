설치 없이 시작하는 방법

Cupid 메인 화면을 열고 새 게임을 선택한 뒤 플레이어 이름을 입력하면 이야기가 시작됩니다. 별도 앱이나 설치 파일은 필요하지 않습니다. 최신 Chrome, Safari, Firefox, Edge처럼 현재 지원되는 브라우저에서 이용할 수 있으며 모바일과 데스크톱을 모두 지원합니다.

처음 접한다면 알림이나 다른 앱을 잠시 정리하고 한 장면씩 읽는 편이 좋습니다. 비주얼 노벨은 빠르게 넘기는 것보다 대사와 표정, 선택 직전의 상황을 함께 보는 장르이기 때문입니다.

저장은 같은 기기와 브라우저를 기준으로

진행 정보는 브라우저 저장 공간을 사용합니다. 같은 기기에서 같은 브라우저를 다시 열면 이어서 플레이할 수 있지만, 다른 기기나 다른 브라우저로 옮기면 저장 상태가 자동으로 따라가지 않을 수 있습니다. 시크릿 모드나 브라우저 데이터 정리를 사용하면 기록이 사라질 수 있으므로 장기간 이어서 볼 계획이라면 일반 창을 이용하세요.

새 게임을 시작하거나 초기화를 선택하기 전에는 현재 기록이 필요한지 확인합니다. 브라우저 저장은 계정 기반 클라우드 저장과 다르다는 점을 기억하면 진행 상태를 관리하기 쉽습니다.

선택지는 호감도만 올리는 버튼이 아닙니다

선택지는 대화의 태도와 관계의 방향을 정합니다. 모든 인물에게 무조건 좋은 반응을 고르려 하기보다 현재 장면에서 플레이어가 실제로 할 법한 말을 선택해 보세요. 한 번의 선택만으로 모든 흐름이 결정되는 것이 아니라 여러 장면에서 쌓인 선택이 루트와 엔딩에 영향을 줍니다.

첫 회차에는 공략 정보를 보지 않고 끝까지 진행하고, 다음 회차에 다른 선택을 비교하면 같은 장면이 어떻게 달라지는지 더 분명하게 볼 수 있습니다. 멀티 엔딩 구조에 대한 설명은 선택지와 멀티 엔딩 안내에서 이어집니다.

일곱 언어와 화면 환경

Cupid는 한국어, 영어, 일본어, 스페인어, 프랑스어, 독일어, 포르투갈어 페이지를 제공합니다. 언어를 바꿀 때는 현재 페이지의 언어 선택을 사용하고, 저장 상태가 언어별 화면에서 어떻게 이어지는지 확인하세요. 작은 화면에서는 세로 방향이 읽기 편하고, 긴 장면을 볼 때는 화면 밝기를 낮추면 대사에 집중하기 좋습니다.

  • 처음에는 한 언어로 회차를 끝까지 진행합니다.
  • 이어하기 전에 같은 브라우저인지 확인합니다.
  • 선택 결과가 궁금해도 장면이 끝나기 전에 페이지를 닫지 않습니다.

처음 플레이하는 사람에게

비주얼 노벨 입문 가이드에서는 선택지, 호감도, 다회차 플레이의 기본을 설명합니다. Cupid는 전체 이야기를 무료로 공개하며 브라우저에서 바로 실행됩니다. 플레이 중 문제가 생기면 먼저 페이지를 새로고침하기보다 저장 상태와 브라우저 설정을 확인하고, 필요한 경우 메인 화면에서 다시 진입하세요.

이어하기가 보이지 않을 때 확인할 항목

같은 기기라도 브라우저가 달라졌거나 사이트 데이터가 삭제되면 이전 기록을 찾지 못할 수 있습니다. 먼저 주소가 `cupid.archerlab.dev`인지, 마지막으로 플레이한 브라우저를 사용 중인지 확인하세요. 홈 화면에 추가한 앱과 일반 브라우저 창이 서로 다른 저장 공간을 사용하는 환경도 있으므로 마지막 실행 방식을 기억해 두는 편이 좋습니다.

브라우저 저장 공간을 제한하는 보안 설정, 시크릿 모드, 자동 데이터 삭제 기능도 기록 유지에 영향을 줄 수 있습니다. 오류가 반복되면 현재 화면과 발생 순서를 메모한 뒤 문의할 때 함께 전달하세요. 이름이나 선택 내용 같은 게임 진행 정보는 설명할 수 있지만 비밀번호, 계정 정보, 실제 개인정보는 보내지 않습니다.
